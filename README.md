# mbdyn — 多频带动态处理器

分频 → 分带检测/增益 → 合成。声明响应为平坦幅度 + LR4 全通相位。

## 图形入口(分带动态操作)

母带试听面板是分带动态的主入口，全部控件都直接驱动内核
(`MultibandEngine`)，内核拒绝会回显为状态消息：

```
python3 -m mbdyn.panel            # 或 python3 -m mbdyn
# 打开终端打印的地址(默认 http://127.0.0.1:8137/)
```

面板内可进行的分带动态操作：

- 拖动分频点(画布上的虚线)实时换带；
- 逐带独奏/静音/开启动态，调整阈值、压缩比、拐点、启动/释放、补偿；
- 旁路与处理开关；
- **运行试听**：显示各带响应曲线、合成曲线、输入/处理 WAV、重组误差、
  各带最大增益衰减、换带策略日志；
- 右侧 **分带动态运行状态** 面板显示每带频率区间、包络(dBFS)与当前增益；
- 分带响应异常与合成试听异常(重组误差超限)会以琥珀色文字标出。

拖动分频点并独奏频段后，分带响应与合成试听仍照常显示(试听时以中性
独奏/静音状态测量合成)。

## 命令行(仅辅助分带动态)

命令行只用于辅助验证分带动态，不是主入口：

```
python3 demo.py       # 输出验证素材到 demo_out/*.wav 并打印测量值
python3 run_tests.py  # 无依赖测试运行器(净目录可直接执行)
```

## 状态归属

- 滤波记忆(`MultibandCrossover` 双二阶状态)—— 属于拓扑；
- 包络记忆(`BandDynamics.env`)—— 属于检测源(频带频率区间)；
- 分带增益 —— `(env, config)` 的纯函数，不保存记忆。

换带时只有检测源未变的频带继承包络；侧链真正改接的频带重建包络，
避免旧增益沿用。详见 `mbdyn/bands.py`。
